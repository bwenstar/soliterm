# Code of conduct

Soliterm follows the [Contributor Covenant, version 2.1][covenant]. Please
read it before you take part. It covers the issue tracker, pull requests,
discussions and anywhere else you're speaking for the project.

The short version: be kind, assume good intent, and keep criticism about the
code rather than the person writing it. Harassment, insults and personal
attacks aren't welcome here, whoever they're aimed at.

## Reporting a problem

If someone's behaviour bothers you, email the maintainer, Brendan Ta, at
the address on the [@bwenstar](https://github.com/bwenstar) GitHub profile
rather than replying in the thread. Reports are kept confidential.

The maintainer may edit or remove comments, commits, issues and other
contributions that break the code of conduct, and may ban someone from the
project for serious or repeated problems. The Covenant's enforcement
guidelines describe the steps.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
