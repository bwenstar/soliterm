# Eight Off

Eight Off is a close relative of FreeCell, played with one deck. Every card is face up from the start and there are eight cells instead of four, but the columns only build in suit, so long runs are harder to put together. It is nearly all skill, and most deals can be won with care.

## The deal

Along the top are eight cells, with the four foundations to their right, and eight columns underneath.

- Each column gets six cards, all face up (48 cards).
- The last four cards go into the four left-hand cells, face up, so you start with four cells free.
- The foundations start empty.

The status line shows how many cells are free.

## Goal

Build all 52 cards onto the four foundations, each one running from Ace to King in a single suit.

## Moves

- **Columns** build down in the same suit: the 9 of hearts goes on the 10 of hearts, and nothing else does.
- You can move the top card of a column, or a run of cards from the top that follows suit downwards, as one move. The longest run you can move is one more than the number of empty cells: five cards at the start, and nine when all eight cells are empty. Empty columns don't add to this.
- An empty column only takes a King, or a run headed by a King (still within the run limit).
- **Cells** hold one card each. The top card of any column can go into an empty cell, and a card in a cell can go back onto a column or up to a foundation.
- **Foundations** start with an Ace and build up in suit to the King, one card at a time. Double-click a card, or press f, to send it to its foundation.
- The top card of a foundation can come back down onto a column or into an empty cell. It gives back the point it earned, and it is seldom worth doing.
- There is no stock and no redeal.

## Scoring

You get one point for each card you put on a foundation, and lose it again if the card comes back off, so the score is always the number of cards on the foundations. A won game scores 52. This matches AisleRiot's one point per foundation card.

## Options

Eight Off has no options.

## Tips

- Cells are what let you move runs, so treat each one as precious. Every card you park shrinks the longest run you can shift by one. Before you fill a cell, make sure you can see how to empty it again.
- An empty column only takes a King, so it is only as useful as the King you can move into it. A King at the head of a column, whether it was dealt there or moved into a space, is the best place to build, since a suit run under it never has to move again.
- Sending cards up never hurts. Because columns build in suit, the only card that could go on a card is the next one down in its suit, and if a card can go up, that one is already on the foundation. Autoplay relies on this and sends up everything it can.
- All 52 cards are visible from the first move, so find the Aces and twos buried deepest and plan which columns to dig out first, before you spend any cells.
